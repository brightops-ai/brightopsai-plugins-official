# BrightOps AI Plugins

Official plugin marketplace for BrightOps AI Claude Code plugins.

## Plugins

- **1password** — Use the 1Password CLI (op) to read, inject, and manage secrets mid-session.

## Installation

Add this marketplace to Claude Code:

```
/plugin → Marketplaces → Add → directory → ~/Projects/brightopsai-plugins-official
```

Then install plugins via `/plugin → Discover`.
